# 에이전트 진입 지시서

> **사람이 AI 에이전트에게 이 폴더를 주면서 시작할 때, 에이전트가 가장 먼저 읽는 문서.**
> 사람이 읽어도 된다 — 그때는 "너" 를 "나" 로 바꿔 읽으면 된다.

---

## 이 폴더가 무엇인가

2026 Aimers 「투구 제구 성공 확률 예측」(최종 팀 Public LB 1130.16)에서
**AI 4종 + 사람 2인이 실제로 시도한 모든 기법**을 코드와 근거로 정리한 것이다(팀 전체는 5인).
채택된 것뿐 아니라 **실패·보류한 것도 전부 코드로** 들어 있다.

**너에게 요구되는 것은 "새로운 아이디어를 내는 것"이 아니라
"이미 검증된 순서대로, 이미 실패한 것을 반복하지 않으면서 진행하는 것" 이다.**

## 지금 당장 할 일 (순서대로)

```bash
cd playbook

# 1) 이 대회에 맞게 config.py 를 채운다
#    id_col / target_col / time_col / fold_edges / entity_cols /
#    context_cols / cumulative_prefixes / metric / 규정 항목
vi config.py

# 2) 검증 — 어떤 기법이 이 대회에 적용 가능한지 자동 판정된다
python3 run.py check

# 3) 계획 확인
python3 run.py plan

# 4) 첫 단계부터
python3 run.py next
```

기법 카탈로그는 이렇게 본다:

```bash
python3 run.py list                 # 전체 50개 (✅29 ❌17 ⏸4)
python3 run.py list --stage 6       # 특정 단계만
python3 run.py list --status REJECTED   # 실패한 것만 (재제안 방어용)
python3 run.py show lookup.entity_residual   # 상세 + 근거 + 구현 위치
```

단계를 마치면 기록한다: `python3 run.py stage 3 --done`

## 반드시 지킬 규율 6가지

이것을 어겨서 이 대회에서 **실제로 점수와 슬롯을 잃었다.**

1. **판정 기준을 결과 보기 전에 적는다.** 어긴 실험이 실전 −4.1 을 냈다.
2. **최소 5시드.** 2~3시드는 노이즈를 4~5배 과소평가한다.
   1폴드×1시드로 판정하고 출하한 것이 −4.1 의 직접 원인이다.
3. **후보를 10개 이상 훑으면 무작위 대조군을 섞는다.** 없으면 대량 탐색은 자기기만 장치다.
4. **출하하는 바로 그 산출물을 검증한다.** 창을 밀거나 재학습했으면 그건 **새 후보**다.
5. **한 번에 하나만 바꿔 제출한다.** 두 개를 묶으면 델타 해석이 불가능하다.
6. **정직한 null 을 보고한다.** 이 대회에서 20+ 축을 빨리 닫은 것이
   결과적으로 가장 생산적인 작업이었다. 억지로 성공을 만들지 마라.

## 하지 말아야 할 것

```bash
python3 run.py list --status REJECTED
```

여기 나오는 16개는 **이미 시도했고 근거와 함께 실패했다.**
새로 제안하기 전에 이 목록부터 확인하라. 특히:

| 기법 | 결과 |
| :--- | :--- |
| 잔차 후처리 모델 (GBDT) | 정직한 분할 통과했는데 **실전 −4.1** |
| 무수축 타겟 인코딩 | **LB 103** (정상 1032) |
| 신경망 종류 늘리기 | ResNet/Transformer/TabNet 전부 손해 |
| 도메인 물리 파생 9종 | **−361** |
| 지식 증류 | 이득의 100%가 분산 수축 |
| 매치업 사전확률 | 단독 +258.6 인데 전방 **−12.1** |

**단, "실패"는 이 데이터에서의 실패다.** 각 항목의 `note` 에 "다른 대회에서는 다시 볼 조건"을
적어 뒀다. `run.py show <id>` 로 확인하라.

## 🚨 특권 피처 경보

**어떤 모델의 단독 성능이 주력보다 크게 높으면 그 자체가 경고다.**
이 대회에서 그런 모델 3종이 **예측 대상 사건 자체의 실측값**을 쓰고 있었고,
그걸 포함해 계산한 천장이 `+113`(도달 가능)이었는데 빼니 `+2.1`이었다.

확인 절차:
1. 그 모델의 피처 목록·메타데이터를 연다
2. 참조하는 외부 파일을 연다
3. **그 파일 행 수가 학습 데이터와 1:1이면** = 각 행의 개별 값 → 특권 피처
4. **테스트 데이터에 그 컬럼이 있는지** 확인 — 없으면 배포 자체가 불가능

## 사람에게 물어야 하는 것

- 대회 규정 원문 (금지·허용 항목)
- 제출 슬롯 수, 순위 산정 방식(최고점 기준인가)
- 팀이 있다면 **판정용 홀드아웃 예측**(`train<Y` → Y 예측)
  — 배포용만 받으면 in-sample 이라 가치를 잴 수 없다. 이 대회에서 실제로 막혔다.

## 사람에게 보고할 때

- 수치는 **직접 재현한 것만** 인용한다
- 로컬 이득을 보고할 때 **폴드·시드 수·대조군 바닥**을 함께 적는다
- 실전 점수를 받으면 `val.transfer_ratio` 에 (로컬Δ, 실전Δ) 쌍을 기록한다
